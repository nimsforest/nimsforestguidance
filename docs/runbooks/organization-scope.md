# Organization scope

The header selector offers All organizations and accessible deployed workspaces. All organizations reads the current workspace plus each other accessible Guidance instance using the signed-in user's session. Each destination checks live membership again. Deployment metadata never grants access. Missing or denied workspaces appear as unavailable reads; totals cover successful reads only.

Portfolio grouping includes organization and entity reference. Cash is not netted between organizations; currencies remain separate. Open a remote forecast in its own workspace for detail, editing or approval. Snapshot exports are available in a specific workspace.

Systems & inputs requires a specific organization. All organizations shows a selection prompt and performs no source or financial-system requests. Selecting an organization opens that workspace, retaining the sources page. Source requests and credentials remain local to the selected organization's services.

Guidance retains management estimates and approved versions; connected providers remain authoritative for actuals. This does not reuse the Forest topology Territory viewmodel as a financial schema.
